计算机网络

第一章 概述

第二章 物理层

2.1 物理层接口的特性

  1. 机械特性
    接口形状，引脚排布等
  2. 电气特性
    规定高低电平电压范围
  3. 功能特性
    规定每条线功能是什么，区分时钟信号、发送信号和接收信号等
  4. 过程特性
    规定通信过程中应该按照什么顺序执行操作

2.2 数据通信系统

2.2.1 组成

  1. 源系统（发送端）
    源点：产生要传输数据的设备

    例如：

    • 你在键盘上输入文字
    • 手机摄像头拍摄照片
    • 麦克风采集声音
    • 传感器采集温度

    发送器：负责将源点产生的数据转换为适合在传输系统中传输的信号
    如果要通过传统模拟电话线路传输，就需要调制解调器将数字数据转换成适合线路传输的模拟信号。

  2. 传输系统（传输网络）它可以非常简单：

    • 一根网线
    • 一段光纤
    • 一条无线通信链路

    也可以非常复杂：

    • 由多个路由器组成的网络
    • 运营商的通信网络
    • 跨越多个国家的互联网骨干网络

  3. 目的系统（接收端）
    接收器：接收器负责接收传输系统传来的信号，并将其转换为目的设备能够处理的信息
    终点：终点就是最终接收并处理数据的设备

2.2.2 消息、数据和信号的区别

息、数据、信号是三个不同层次的概念。

  • 消息：传递什么内容。
  • 数据：如何表示这些内容。
  • 信号：如何通过物理介质传输这些数据。

2.2.3 模拟信号和数字信号

模拟信号的参数取值是连续的：人的声音通过麦克风转换成的模拟电信号等

数字信号的参数取值是离散的：使用高低电平表示二进制的 0 和 1等

码元：使用时域波形表示数字信号时，代表不同离散数值的基本波形称为码元（Symbol）一个码元不一定只能表示一个比特，如果采用多进制编码，一个码元可以代表多个比特

2.2.4 信道

信道一般用于表示向某一个方向传送信息的媒体，信道和通信电路不是同一个概念一条通信电路往往包含：

  • 一条发送信道
  • 一条接收信道

因此有三种基本通信方式

  1. 单向通信：单工通信 Simplex，例如：广播
  2. 双向交替通信：半双工通信 Half-Duplex，例如：对讲机
  3. 双向同时通信：全双工通信 Full-Duplex，例如：传统电话

这里的信道是按信息传输方向划分的逻辑概念，具体物理实现不一定需要两根独立的线路，比如广播就不依靠独立的线路

2.2.5 基带信号和带通信号

计算机产生的是数字比特流。

例如：

这种由信源产生、未经频谱搬移的原始信号，教材称为基带信号（Baseband Signal）。

因为基带信号通常包含较多低频分量，甚至包含直流分量。

而很多信道无法直接传输这些低频分量或直流分量。

所以我们需要对基带信号进行调制。

基带调制：对基带信号的波形进行变换，使其适应信道的特性，变换后的信号仍然是基带信号，由于这种过程通常是将一种数字信号转换成另一种数字信号，因此也称为编码
带通调制：将基带信号加载到高频载波上，使信号的频率范围移动到适合信道传输的频段

2.2.6 常用的数字信号编码方式

  1. 不归零制 NRZ
    每个比特周期内，信号保持对应电平，不需要在每一位结束时返回零电平
    当连续发送很多相同的比特时，信号可能长时间没有跳变，缺乏自同步能力

  2. 归零制 RZ

每个比特周期中，信号都会返回零电平，看前半段

  1. 曼彻斯特编码 Manchester
    每一个比特周期的中间都一定发生一次电平跳变，看中间跳变方向

  2. 差分曼彻斯特编码
    它不直接通过中间跳变方向区分 0 和 1，而是通过每一位开始边界是否发生跳变来表示数据，看起始位置是否存在跳变

编码方式 主要特征 自同步能力
NRZ 正负电平表示 1、0 较弱
RZ 每位返回零电平 有一定帮助
Manchester 每位中间必有跳变 有
Differential Manchester 中间必有跳变，边界变化表示数据 有

这里最重要的区别是：

曼彻斯特编码通过中间跳变的方向表示数据；差分曼彻斯特编码通过位开始边界是否跳变表示数据。

2.2.7 基本的带通调制方法

带通调制主要有三种基本方式：

  1. 调幅 AM。

  2. 调频 FM。

  3. 调相 PM。

  4. 正交振幅调制 QAM

    它通过同时利用振幅和相位的变化来表示不同的数据状态。

    相比单纯调幅、调频或调相，它能够使用更多不同的信号状态。

    这就为提高数据传输速率提供了条件。

2.2.8 信道的极限容量

码间串扰：当信道带宽有限时，信号中的高频分量会受到衰减，原本边界清晰的数字脉冲会逐渐变得模糊，如果相邻码元的波形相互重叠，就可能造成码间串扰

奈氏准则：在带宽为 W Hz 的理想低通信道中，如果不考虑噪声影响，码元传输的最高速率为 2W 码元/秒

Rs.max = 2W

其中：

  • (Rs)：码元传输速率，单位 Baud（波特）。
  • (W)：信道带宽，单位 Hz。

这里计算的是码元速率，不一定等于比特率。

一个码元能携带多少比特

将奈氏准则的码元速率换算成比特率。一般来说，如果有 V 种不同的信号状态，每个码元可以携带：

Rb.max = 2W log_2 V

信噪比（SNR）

信号状态越多，接收端越难准确区分它们。

因此，我们还必须考虑噪声。

SNR = S/N

其中：信噪比越高，说明信号相对于噪声越强，通常越容易正确识别。

  • (S)：信号平均功率。
  • (N)：噪声平均功率。

通信中经常使用 dB（分贝）表示信噪比:

SNR(dB) = 10 lg (S/N)

香农公式：它考虑了信道带宽和信噪比对数据传输速率的限制

C = W log_2 (1 + S/N)

符号 含义 单位
C 信道极限信息传输速率 bit/s
W 信道带宽 Hz
S 信号平均功率 功率单位
N 噪声平均功率 功率单位
S/N 信噪比 无单位

这里有一个特别容易犯的错误：

公式中的 S/N 必须使用普通比值，不能直接把 dB 代入。

  • 奈氏准则：带宽决定码元速率上限。
  • 香农公式：带宽和信噪比共同决定信息传输速率上限。

2.3 传输媒体

2.3.1 导引型传输媒体

主要包括：

  1. 双绞线
    两根导线按照一定规则相互缠绕，形成一对双绞线，两根导线传输的是一对相关的电信号，接收端主要检测两根导线之间的电压差，而不是单独检测某根导线的电压。两根线上受到的相似干扰可以在差分接收时得到抑制

    UTP：非屏蔽双绞线
    STP：屏蔽双绞线，减少外部电磁干扰，但成本和安装要求通常更高

  2. 同轴电缆
    从内向外主要包括四部分：

    1. 内导体：负责传输电信号
    2. 绝缘层：隔离内外导体
    3. 外导体屏蔽层：提供回流路径，同时起到屏蔽作用
    4. 保护外套：保护内部结构

  3. 光纤
    利用光信号代替电信号传输数据

    光纤使用光信号传输，具有明显优势。

    例如：

    • 传输带宽大。
    • 通信容量大。
    • 抗电磁干扰能力强。
    • 适合远距离传输。
    • 保密性相对较好，不容易受到普通电磁窃听方式影响。

    分类

    • 多模光纤（Multimode Fiber）。
      多模光纤中的不同传播模式可能走不同的路径，同一个光脉冲到达接收端的时间可能不同->模态色散
    • 单模光纤（Single-mode Fiber）。

2.3.2 非导引型传输媒体

非导引型传输媒体不需要使用固定的有形导体引导信号传播，而是通过自由空间传输电磁波。

  1. 无线电波
  2. 微波
  3. 卫星通信
  4. 红外线和激光

2.4 信道复用技术

复用器（Multiplexer）：将多个用户的数据组合起来，通过共享线路发送。

分用器（Demultiplexer）：在接收端将数据分离，还原成各个用户的数据流。

2.4.1 频分复用FDM

保护频带：实际信号并不是理想的，频谱可能存在扩展和相邻信道干扰，如果两个用户的频带完全紧挨着，可能发生相互干扰

2.4.2 时分复用TDM

同步时分复用 STDM

统计时分复用 STDM

2.4.3 波分复用WDM

密集波分复用 DWDM

EDFA（Erbium-Doped Fiber Amplifier），掺铒光纤放大器。 EDFA 可以直接对光信号进行放大，不需要先进行光电转换再进行电光转换

2.4.4 码分复用

每个用户分配一个不同的、具有良好相关性的码序列

一个用户的码序列与另一个用户的码序列内积为零

例如：

A 的比特1 -> S = (1,-1,1,-1)

B 的比特1 -> T = (1,1,-1,-1)

叠加信号 R = S+T

区分信号A: S = R * S / (码片数量 = 4)= (S + T) S / 4= S * S /4

2.5 数字传输系统

数字通信相对于模拟通信，在传输质量和经济性方面具有明显优势目前长途干线大都采用时分复用 PCM 的数字传输方式。

  • 准同步：各设备使用相互独立但精度较高的时钟，存在微小频率偏差。
  • 同步：各设备按照统一的时钟基准工作。

SONET：同步光纤网

  1. 建立统一的数字传输速率等级。
  2. 实现同步传输。
  3. 适应光纤高速、大容量传输。

基础速率：51.840Mbit/s 这个基础等级有两个不同的名称：

  • STS-1：针对电信号，称为第一级同步传送信号。
  • OC-1：针对光信号，称为第一级光载波。

SONET 速率按照整数倍增长（采用了分级复用的设计思想）

SDH：同步数字体系

SONET 是美国提出的同步光纤传输标准，SDH 是国际电信联盟在此基础上制定的国际同步数字传输体系

2.6 宽带接入技术

2.6.1 ADSL 技术（非对称数字用户线）

ADSL 是利用数字技术改造现有模拟电话用户线，使其能够承载宽带数字业务的一种接入技术

对于普通家庭用户而言，通常下载的数据量远远大于上传的数据量。所以 ADSL 将更多的带宽分配给下行通信，即上下行通道带宽分配不一样

ADSL 能够同时打电话和上网：不同频率的信号分配给不同用途

ADSL 的核心技术：DMT 调制（离散多音调制技术）：

将一个较宽的频带划分为多个较窄的子信道，利用多个不同频率的载波并行传输数据

假设一条电话铜线的传输质量不是特别好。

不同频率的信号受到干扰的程度可能不同。

例如：

  • 低频部分传输质量很好。
  • 中频部分受到一定干扰。
  • 高频部分受到严重干扰。

如果整个频带采用统一的传输方式，就可能无法充分利用质量较好的频率资源。

DMT 的解决方案是：

把整个频带划分为很多较小的子信道，每个子信道可以根据实际情况独立调制

2.6.2 ADSL 接入网络的组成

DSLAM：数字用户线接入复用器：汇聚多个用户的 ADSL 接入线路，并将用户数据集中转发到运营商网络。

ATU：ADSL 调制解调器

  • ATU-C：运营商侧的 ADSL 调制解调设备。
  • ATU-R：家庭侧的 ADSL 调制解调设备。

Splitter：电话分离器

2.6.3 光纤同轴混合网（HFC 网）

同时提供电视、电话和互联网数据交互等功能

核心：将光纤和同轴电缆结合起来，构建宽带接入网络。

HFC 用光纤承担长距离主干传输，用同轴电缆完成最后一段用户接入：可以减少放大器数量（光线抗干扰能力强，损耗小）

双端通信的实现方式：

HFC 使用频分复用的思想，将上行和下行安排在不同的频率范围内

  • 上行：用户家庭 → 同轴电缆 → 光纤节点 → 光纤 → 头端

  • 下行：头端 → 光纤 → 光纤节点 → 同轴电缆 → 用户家庭

HFC如何接入互联网：

  1. 机顶盒（Set-top Box）
    早期电视机主要接收模拟电视信号，现在有线电视网络传输的是数字电视信号，在同轴电缆和电视机之间连接一个机顶盒，负责将数字电视信号转换成电视机能够处理的信号
  2. 电缆调制解调器（Cable Modem）
    实现计算机数字数据与 HFC 网络传输信号之间的转换，使用户能够通过有线电视网络接入互联网。

3. 数据链路层

3.1 数据链路层的基本概念

链路：物理线路

数据链路：链路+必要的通信协议

帧：将网络层交下来的 IP 数据报添加首部和尾部，封装成帧

  • 首部：包含控制信息，例如地址、类型等。
  • 数据部分：通常承载网络层交下来的 IP 数据报。
  • 尾部：可能包含差错检测信息，例如 CRC 校验序列。

为什么每经过一个路由器，都需要重新处理数据链路层

第一步：主机 A 将 IP 数据报封装成帧，发送给 R1。

第二步：R1 收到帧，检查并去掉数据链路层首部和尾部，取出 IP 数据报。

第三步：R1 根据 IP 地址决定下一跳，再使用下一条链路对应的数据链路层协议重新封装成帧。

第四步：R2 重复这个过程。

第五步：最终到达主机 B。

这里产生了一个非常重要的结论：

IP 数据报可以在整个通信过程中保持端到端的逻辑传输，而数据链路层的帧是逐段传输的，每经过一个路由器，都可能重新封装。

所以不同链路可以使用不同的数据链路层协议

3.2 数据链路层的三个基本问题

3.2.1 封装成帧

让接收方识别帧的开始和结束

教材介绍了一种使用特殊控制字符的方法

SOH ABCDEF EOT

接收方读取到 SOH，就知道一帧开始了。

读取到 EOT，就知道这一帧结束了。

最大传送单元 MTU：表示数据链路层协议所允许的帧中数据部分的最大长度，是数据部分的最大长度，不是整个帧的最大长度，如果 IP 数据报超过 MTU，就需要根据网络层的相关机制进行处理，例如分片或其他适当处理

**3.2.2 **透明传输

保证数据中出现特殊控制字符时，不会破坏帧的边界识别

如果数据中出现与帧边界控制字符相同的特殊字符，就在它前面插入一个转义字符 ESC(包括自己)

接收方读取时：

  1. 看到 SOH，知道一帧开始。
  2. 看到 ESC，知道下一个字符是被转义的数据。
  3. 因此不会把后面的 EOT 当成真正的帧结束标志。
  4. 继续读取，直到遇到没有被转义的 EOT。

3.2.3 差错检测

CRC 循环冗余检验

CRC 是一种计算校验码的方法，FCS 是添加到帧中的校验字段

计算原理：

使用教材中的例子。

假设：

原始数据：

M=101001

生成多项式对应的二进制除数：

P=1101

由于 P 有 4 位，因此它的最高次数为 3。

所以需要在原始数据后面补 3 个 0。

M′=101001000

接下来：

用补零后的数据除以生成多项式，采用模 2 除法。

101001000÷1101

得到余数：

R=001

因此，发送方需要将余数附加到原始数据后面：

T=M+R

T=101001001

这里的加号表示拼接，不是普通算术加法。

这就是最终发送的数据。

检验方法：

发送方发送：

T=101001001

接收方收到数据后，使用同一个生成多项式：

P=1101

进行模 2 除法。

如果：

T÷P

余数为 0，那么说明没有检测到传输差错。

如果余数不为 0，则说明检测到了差错。

没有比特错误，不代表没有传输错误所以还需要可靠传输

3.3 点对点协议PPP

PPP 主要用于两个节点之间的点对点通信，这条连接需要遵循统一的通信规则

3.3.1 特点

  1. 简单
    不需要复杂的可靠传输机制，如果接收方收到一个 CRC 校验错误的帧，直接丢弃
    因为 PPP 主要用于点对点全双工链路，设计目标是尽量简化协议，如果上层需要可靠传输，可以由上层协议实现
  2. 封装成帧
    PPP 必须规定特殊的帧定界符
  3. 透明性
  4. 支持多种网络层协议
    假设同一条点对点链路上，需要传输不同类型的网络层数据，PPP 可以通过协议字段识别不同类型的数据，并交给相应的网络层协议处理
  5. 支持多种类型的链路
  6. 差错检测
    PPP 使用 CRC 进行差错检测。如果发现帧出现差错，就将其丢弃
  7. 检测连接状态
    PPP 能够检测链路是否处于正常工作状态
  8. 最大传送单元 MTU
  9. 网络层地址协商
  10. 数据压缩协商

3.3.2 组成部分

1. 封装方法

3.3.3. 帧格式

  1. 标志字段
  2. 地址字段
    PPP 是点对点协议，两端之间只有两个通信实体，因此这个地址字段实际上没有真正的寻址作用
  3. 控制字段 （固定值 0x03=00000011）
    表示无编号帧
  4. 协议字段
    用来说明信息字段中承载的是什么类型的数据，从而交给谁处理，IP、LCP等
  5. 信息字段（长度可变）
    教材规定，默认 MTU 为 1500 字节
    存放真正需要传输的数据，例如：
    • IP 数据报
    • LCP 控制数据
    • NCP 控制数据
  6. 帧检测序列 FCS
  7. 结束标志 0x7E
协议字段 含义
0x0021 IP 数据报
0xC021 LCP 数据
0x8021 NCP 数据（IPCP）

基本过程：

假设计算机 A 要通过 PPP 向计算机 B 发送一个 IP 数据报。

那么：

  1. 先在 IP 数据报前添加 PPP 帧首部。
  2. Protocol 字段填写 0x0021，表示承载的是 IP 数据。
  3. 信息字段存放 IP 数据报。
  4. 计算 CRC，生成 FCS。
  5. 在帧首尾添加 0x7E。
  6. 通过物理链路发送。

接收端按照相反的过程处理：

  1. 识别帧边界。
  2. 检查 FCS。
  3. 根据 Protocol 字段判断数据类型。
  4. 将 IP 数据报交给 IP 层处理。
异步传输：字符填充法

异步传输通常以字节为单位进行数据传输

异步传输是面向字节的，转义后的第一个字节是7D第二个字节，是原字符与 0x20 异或后的结果，例如：

信息字段出现 0x7E：

替换为：0x7D, 0x5E

同步传输：零比特填充法

同步传输以连续的比特流进行传输，不需要为每个字节单独添加起始位和停止位

这种方法面向比特

发送方扫描信息字段，每遇到连续五个 1，就立即插入一个 0

接收方如果发现连续五个 1 后面紧跟一个 0，就删除这个 0

因为 PPP 的帧边界标志：01111110中间存在连续六个 1，而通过零比特填充，可以保证数据字段中不会直接出现这种完整的标志序列

3.3.4 PPP协议的工作状态、

PPP 工作状态转换

  1. 链路静止（Link Dead）

    尚未建立物理连接。

    你还没有点击宽带连接按钮，电脑与运营商之间尚未建立相应的物理连接

  2. 链路建立（Link Establish）

    物理连接建立后，通过 LCP 协商链路参数。

    你点击了宽带连接按钮，调制解调器开始呼叫运营商的接入设备，当运营商检测到调制解调器发出的载波信号后，就建立物理连接，物理连接建立，不代表 PPP 链路已经配置完成，接下来需要 LCP 工作，LCP 会发送配置请求，运营商检查之后，如果接受，就返回 Configure-Ack，如果不接受某个参数值，可以返回 Configure-Nak，如果某个配置选项无法识别或不支持，可以返回 Configure-Reject，LCP 配置完成，只代表数据链路层的链路参数已经协商好，并不意味着 IP 地址已经配置完成

  3. 鉴别（Authenticate）

    如果需要身份验证，双方进行身份鉴别。

  4. 网络层协议（Network-Layer Protocol）

    通过 NCP 配置网络层协议，例如 IPCP 配置 IP 参数。IPCP 可以协商 IP 层相关参数，例如 IP 地址，NCP 不只是 IPCP，还可以用于其他网络层协议的配置

  5. 数据传输

    链路配置完成，开始传输网络层数据。

  6. 链路终止（Link Terminate）

    双方释放链路，最终返回链路静止状态。

3.4 使用广播信道的数据链路层

3.4.1 局域网

网络通常为一个单位所拥有，而且地理范围和站点数目有限。

局域网拓扑结构：

  1. 星型网：所有计算机连接到中央设备，例如交换机
    优点：结构清晰，容易管理

    缺点：中心设备发生故障可能影响整个网络

  2. 环形网：每个节点与相邻节点连接，形成闭合环路

    数据可以沿环路传输

  3. 总线网：所有计算机共享一条总线

    一个节点发送的数据可以被总线上其他节点接收

局域网的数据链路层为什么划分为两个子层？

例如一个公司使用两种局域网，它们的物理传输介质、访问方式可能不同，网络层是否需要针对每一种局域网技术分别设计一套接口？显然不方便

网络层 -> LLC（逻辑链路控制子层） -> MAC （媒体接入控制子层）-> 物理层

  1. LLC
    它主要负责向网络层提供统一的服务接口，LLC 子层与具体的传输媒体和 MAC 子层实现相对独立，上层网络层不需要关心底层究竟采用哪种具体的局域网技术，只需要通过 LLC 提供的接口使用数据链路层服务即可
  2. MAC
    控制多个节点如何访问共享信道、处理 MAC 地址、按照相应的 MAC 协议发送和接收帧，解决数据发送冲突的问题
  • LLC 负责提供相对统一的上层接口。
  • MAC 负责处理具体的媒体访问问题。

这样就能够让网络层和不同的局域网底层技术相对独立。

适配器的作用（网络接口卡、网卡、网络适配器）

  • 计算机连接局域网的硬件接口

主要作用

  1. 数据转换：计算机内部通常通过总线与适配器交换数据，而网络介质上传输的是串行比特流，因此适配器需要完成串行传输和并行传输之间的转换
  2. 帧的封装与解封装：
    发送时，计算机将数据交给网卡，网卡按照相应的数据链路层协议封装成帧
    接收时，网卡接收帧，进行相应的检查和处理，再将数据交给计算机。
  3. 差错检测：网卡可以检查接收到的帧的 FCS，发现差错后丢弃错误帧。
  4. 缓存数据：适配器具有自己的存储器，可以暂存发送和接收的数据。
  5. 处理 MAC 地址：网卡具有 MAC 地址，用于在局域网中标识网络接口。

适配器主要实现数据链路层和物理层的功能

3.4.2 CSMA/CD协议

Carrier Sense Multiple Access with Collision Detection载波监听多点接入 / 碰撞检测

让多个计算机能够合理地使用共享信道，这就是 CSMA/CD 的设计目的

**CS：Carrier Sense（载波监听）**发送数据之前，先监听信道是否空闲

**MA：Multiple Access（多点接入）**多个计算机可以连接到同一条共享信道

**CD：Collision Detection（碰撞检测）**发送数据的同时监听信道，检测是否发生碰撞

核心步骤：先听后发，边听边发，冲突停止，延迟重发。

  1. 发送方准备发送数据之前，先监听总线
    信道空闲：立即发送
    信道忙碌：继续监听，等待信道变为空闲
  2. 边听边发：防止信号传播时延造成的误认为空闲，从而双方都发送数据
  3. 冲突停止：立即停止发送原始数据，发送人为干扰信号->让其他相关节点也能够检测到碰撞
  4. 延迟重发：发生碰撞之后，不能立即重新发送，需要采用随机退避机制，避免无限重发
    二进制指数退避算法

争用期：在发送数据之后的一段时间内，仍然存在发生碰撞的可能性 2*传播时延

以太网规定最小帧长：**发送一帧数据所需要的时间，至少要大于等于争用期。**避免发送方误认为数据已经发送成功

基本计算公式：L = 2 * 传播时延 * 数据发送速率

经典以太网最小帧长 64Byte

物理层的传播时延，会影响数据链路层的最小帧长。

二进制指数退避算法：

碰撞次数越多，可选择的随机等待范围就越大

n ：碰撞次数

k = min (n, 10)

r = {0, 1, ..., 2^k - 1}

T = r * 争用期

3.6 以太网的信道利用率

有效发送帧的时间：T0

整个信道被占用的时间：T0+τ

信道利用率：S = T0/（T0 + τ）= 1 / (1 + a)

a = T0 / τ

所以以太网的参数 a 应当尽可能小

有两个方向：

  1. 减小传播时延 τ。
  2. 增大帧发送时间 T0。

联系实际：

  • 缩短以太网的传输距离，可以减小传播时延。
  • 在传输速率固定时，增加帧长度，可以增大帧发送时间。

这也解释了为什么以太网的连线长度会受到限制，以及为什么帧不能无限短

  3. 多播地址

正常情况下如果目的地址不是自己的地址，也不是自己需要接收的广播或多播地址，通常就会丢弃，混杂模式下，网卡会将接收到的各种数据帧交给上层处理，而不只是接收目的 MAC 地址匹配自身的帧，例如wireshark流量分析

3.8 扩展的以太网

3.8.1 物理层的扩展

  1. 使用中继器

中继器：中继器工作在物理层，因为它只处理物理信号，不理解数据链路层的帧结构

中继器连接的两个网段属于同一个网络，因为中继器只负责信号再生，不会解析数据帧，也不会进行网络层寻址，中继器不能隔离碰撞域

  1. 使用光纤

需要使用两端的光线调制解调器实现光电信号的转换

光纤链路虽然改变了物理传输介质，但并没有因此自动隔离两个网段的碰撞域

物理层扩展只能扩大网络的物理覆盖范围，不能真正实现不同网络之间的逻辑隔离。

3.8.2 数据链路层扩展以太网

能够真正理解以太网帧，并根据目的 MAC 地址决定数据应该发送到哪里

核心设备：

  • 网桥（Bridge）
    网桥能够识别 MAC 帧，并根据 MAC 地址决定是否转发数据帧
  • 以太网交换机（Ethernet Switch）
    以太网交换机本质上是一个多端口网桥

特点：

  1. 每个端口都是一个独立的碰撞域，交换机能够隔离碰撞域
  2. 交换机可以实现全双工通信
  3. 交换机可以同时进行多对通信
    假设有一台具有10个端口的交换机，每个端口的传输速率为10 Mb/s，在集线器环境下，10台计算机共享10 Mb/s的带宽，而交换机环境下，每台计算机都可以获得独立的10 Mb/s链路，减缓总能力可到达100Mb/s
  4. 交换机采用存储转发方式
    存储转发：有转发延时，但能发现错误帧
    直通交换：延时小，但是错误帧也会转发
以太网的自学习功能

通过交换表，记录每次源MAC地址是谁发的，把地址和对应计算机端口联系起来，表是由交换机自动学习建立的

例子：

A发送数据帧包含

  • 源MAC地址
  • 目的MAC地址

交换机把源MAC地址和A端口对应，交换机是通过源 MAC 地址学习设备位置的，而不是通过目的 MAC 地址学习

在查询目的地址，如果不在表中就进行泛洪（将这个帧转发到除接收端口之外的其他端口），等到B回复A的时候，交换机再记录下B的MAC地址

交换机使用 CAM（Content Addressable Memory），即内容寻址存储器

给定内容，直接查找与之匹配的存储项，可以用于快速查找交换表

假设 A 向局域网发送一个广播帧。

交换机1收到广播帧后：

  • 从连接交换机2的端口转发。
  • 从其他需要转发的端口转发。

交换机2收到之后，也会将广播帧转发到其他端口。

由于两台交换机之间存在环路，广播帧可能再次回到交换机1。

交换机1又会继续转发。

网络环路问题：使用STP（生成树协议）在逻辑上解决环的生成，使整个交换网络形成一棵无环路的树。

3.8.3 虚拟局域网 VLAN

即使交换机可以根据 MAC 地址定向转发单播帧，遇到广播帧时，它仍然需要向同一个广播域中的其他端口转发，我们还希望不同部门之间保持一定程度的网络隔离。由于物理上建立成本和管理不方便，于是提出VLAN

VLAN 是由局域网网段构成的、与物理位置无关的逻辑组。每一个 VLAN 都是一个独立的广播域。

VLAN 可以在同一套物理网络设备上，划分出多个逻辑局域网

交换机如何区分不同 VLAN？

假设两台交换机之间只有一根网线，但这根网线需要同时传输 VLAN 10、VLAN 20、VLAN 30 的数据，交换机收到帧后，如何知道它属于哪个 VLAN？

在以太网帧中添加 VLAN 标签。

因此，传统最大长度为1518字节的以太网 MAC 帧，添加标签后，最大长度变1518 + 4

VLAN标签具体字段 = TPID（2字节 标识802.1Q 标签） + TCI（2字节

包含优先级等控制信息和 VLAN ID）

VLAN ID 不是 MAC 地址，它只是用来标识帧属于哪个逻辑局域网

Access 和 Trunk：交换机端口如何工作？

Access 端口通常用于连接终端设备，交换机收到帧之后，根据端口配置判断所属VLAN，向普通终端设备发送时，Access 端口通常发送不带 VLAN 标签的以太网帧

Trunk 端口通常用于连接交换机，允许多个 VLAN 的数据帧共用一条物理链路传输

A->C:同一个 VLAN 可以跨越多台交换机。

  1. A 将普通以太网帧发送给 S1。
  2. S1 根据接入端口判断它属于 VLAN 10。
  3. S1 通过 Trunk 发送时，在帧中携带 VLAN 10 标签。
  4. S2 收到帧，根据 VLAN 标签判断它属于 VLAN 10。
  5. S2 将该帧转发到 C 对应的 Access 端口，通常移除标签后交给 C。

A->D:这时就不能像同 VLAN 通信那样，单纯依靠普通二层交换机进行转发，因为 VLAN 10 和 VLAN 20 是两个独立的广播域，普通二层交换机不会直接在不同 VLAN 之间转发帧，如果希望它们通信，就需要引入网络层转发设备，这种方式叫做VLAN 间路由（Inter-VLAN Routing）。

  • 总结：集线器不能隔离碰撞域、交换机能够隔离碰撞域、VLAN可以划分广播域

3.9 高速以太网

3.9.1 100BASE-T 以太网

100BASE-T 又称快速以太网（Fast Ethernet）

快速以太网尽可能保持与传统以太网的兼容性

具体来说：

  • 仍然采用以太网 MAC 帧格式。
  • 保留原来的 MAC 地址结构。
  • 保留 CSMA/CD 协议的半双工工作方式。
  • 全双工方式下不需要 CSMA/CD。

速率提高10倍，发送相同大小的帧所需要的时间缩短为原来的十分之一，如果仍然使用 CSMA/CD，就必须保证碰撞能够在发送结束前被检测到，因此，提高传输速率的同时，也需要考虑传播距离和碰撞检测时间之间的关系，因此受传输距离限制

不过在实际交换式全双工以太网中，不再依赖 CSMA/CD，因此不受这一碰撞检测条件的限制

3.9.2 吉比特以太网

每秒可以传输10亿比特 1Gb/s

四个主要特点：

  1. 允许全双工和半双工两种工作方式。
  2. 使用 IEEE 802.3 标准规定的帧格式。
  3. 半双工方式使用 CSMA/CD，全双工方式不使用 CSMA/CD。
  4. 在全双工方式下，可以使用交换机实现高速通信。

速率更快所以争用期会大大减少，在帧后添加载波延伸比特，使发送过程持续足够长的时间，载波延伸以达到碰撞检测的功能

分组突发：每个短帧都必须进行载波延伸，会产生很多额外开销，第一个短帧使用载波延伸满足最小占用时间要求，之后可以连续发送多个短帧，而不必为每一个短帧都单独进行完整的载波延伸。

3.9.3 10吉比特以太网及更高速的以太网

主要特点：

  1. 与传统以太网使用相同的 MAC 帧格式。
  2. 只支持全双工通信。
  3. 不再使用 CSMA/CD 协议。
  4. 主要通过光纤或高速铜缆传输。

10吉比特以太网不再支持半双工，也就不再需要 CSMA/CD。

3.9.4 使用以太网进行宽带接入

FTTB：光纤到楼

理解这个过程：

  1. 运营商通过光纤将网络接入大楼。
  2. 大楼内部通过 ONU 等设备完成光电转换和网络接入。
  3. 再通过以太网交换机将网络分发给各个用户。
  4. 用户通过网线连接到交换机提供的网络接口。
FTTH：光纤到户
比较 FTTB FTTH
光纤到达位置 大楼 用户家庭
用户最后一段接入 通常使用双绞线 使用光纤
光网络终端 通常位于楼内 通常位于用户家中
PPPoE

用户计算机->以太网->PPPoE->PPP->运营商网络

PPPoE 将 PPP 帧封装在以太网帧中，使用户能够利用以太网接入方式完成类似传统 PPP 拨号的认证和连接管理

4. 网络层

4.1 网络层提供的两种服务

网络层向上提供服务，运输层使用这些服务完成主机之间的数据通信

  1. 面向连接的虚电路服务（Virtual Circuit）。
  2. 无连接的数据报服务（Datagram）。

4.1.1 虚电路服务

在真正传输数据之前，先建立一条逻辑上的通信路径，然后沿着这条路径传输数据

A在网络1，B在网络4，中间经过路由器1，2，3

  1. 建立连接
    A 想与 B 通信，首先向网络发送建立连接的请求，网络选择一条路径 A->1->2->3->B
    沿途的路由器需要建立相应的虚电路状态信息例如R1

  2. 数据传输
    连接建立之后，A 就可以发送数据了，每个分组不需要每次都重新决定一条完整的路径，而是根据虚电路标识找到对应的转发状态

  3. 释放连接
    数据传输完成后，A 通知网络释放虚电路，沿途路由器删除相应的连接状态。

特点：

虚电路并不意味着独占物理链路，多个虚电路仍然可以共享同一条物理传输线路

4.1.2 无线连接的数据服务

每一个分组独立发送，每个路由器根据分组中的目的地址，独立决定下一步应该往哪里转发

A 想向 B 发送数据，假设 A 将数据拆成三个分组：1，2，3，这三个分组都包含目的主机 B 的 IP 地址，但它们可以分别选择不同的传输路径

路由器收到分组后：

  1. 读取目的 IP 地址。
  2. 查询路由转发表。
  3. 找到下一跳。
  4. 转发给下一台路由器。

不需要提前建立一条专门的虚电路。

不保证数据按照发送顺序到达

为什么互联网最终采用数据报服务？

  1. 网络核心更加简单
    减少网络状态管理的负担，不需要每次通信都建立虚电路
  2. 更加灵活
    虚电路中途可能无法继续使用
  3. 可靠性由端系统负责
    网络层提供尽可能简单的基本传输服务，复杂的可靠性控制可以由端系统实现

4.2 网络层的两个层面

手机 → 路由器A → 路由器B → 路由器C → 服务器

  • 路由器 A 如何知道应该把数据交给 B？
  • 谁决定 A、B、C 这条传输路径？
  • 如果 B 出现故障，谁负责重新计算路径？
  • 路由器收到数据后，谁负责真正把数据转发出去？

4.2.1 数据平面：负责转发数据

数据平面主要负责在一台路由器内部，将分组从输入接口转移到合适的输出接口，数据平面不负责决定整个互联网应该如何规划路线，它负责按照已有的转发规则执行转发

  1. 读取目的 IP 地址。
  2. 查询自己的转发表。
  3. 找到对应的输出接口。
  4. 将数据报转发到下一跳。

4.2.2 控制平面：负责路由选择

控制平面负责网络范围内的路由选择，计算数据应该经过哪些路由器才能到达目的网络，并生成或更新路由信息，选择下一跳

  • 路由选择：决定应该走哪条路。
  • 分组转发：按照确定的规则，把分组送到下一跳

二者是如何组织起来的？

传统网络架构：分布式控制平面

每一台路由器同时具备数据平面和控制平面，路由器之间交换网络信息，各自计算路由，并更新自己的转发表。

SDN：软件定义网络

将网络的控制平面与数据平面分离

  • SDN 控制器负责集中管理网络控制逻辑。
  • 交换机主要根据控制器下发的流表规则进行转发。
  • 控制器可以统一调整整个网络的转发策略。

通过控制器统一下发相应的转发规则

4.3 网际协议IP

不同网络可能采用不同的物理传输模式、帧格式和地址体系，比如以太网使用 MAC 地址识别链路上的设备，而不同类型的网络可能采用不同的链路层地址机制。因此，我们需要一种统一的网络层协议。

在不同类型的物理网络之上，建立统一的逻辑通信体系。

底层网络可以完全不同，但是只要它们都能够承载 IP 数据报，就可以通过路由器实现互连

虚拟互联网：虽然底层实际由许多不同类型的物理网络组成，但是通过统一的 IP 协议，从网络层的角度看，它们形成了一个统一的逻辑网络
